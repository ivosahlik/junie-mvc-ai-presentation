Tohle je trochu chyták 🙂 — „AI Credits“ ≠ „tokeny“.

Tokeny jsou technická jednotka textu (kousky slov), které model zpracovává.

AI Credits je spíš obchodní / billingová jednotka (balíček předplacených peněz).

1 kredit obvykle = určitá částka v USD (např. 1 AI Credit = 1 USD, ale to záleží na poskytovateli).

Kolik tokenů za to dostaneš, záleží na ceníku konkrétního modelu.
